# Mufa Arena

Game #4 Mufa Games. HTML5 + CSS3 + JavaScript murni, Canvas 2D, tanpa aset eksternal.

## Menjalankan
Buka `index.html` di browser, atau upload folder ini ke hosting statis (mis. GitHub Pages).
