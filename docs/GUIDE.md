# Panduan bermain Mufa Arena

## Dasar
- Kamu mengendalikan lingkaran cyan di arena tertutup. Hindari serangan, tembak musuh, dan selesaikan objektif mode.
- **Health** (bar hijau) berkurang saat disentuh musuh atau terkena proyektil dan jebakan. Setelah terkena, kamu kebal sebentar (karakter berkedip), jadi damage tidak dihitung dua kali.
- **Energi** (bar cyan) dipakai kemampuan dan terisi sendiri.
- **Tembakan** otomatis jika ada musuh searah bidikanmu. Kamu juga bisa menembak manual (klik atau Space).
- Item hijau memulihkan health, tapi punya batas waktu.

## Musuh
| Musuh | Perilaku |
|---|---|
| Chaser (lingkaran) | Mengejar langsung. Berbahaya jika berkelompok |
| Shooter (belah ketupat) | Menjaga jarak dan menembak |
| Tank (segi enam) | Lambat, health besar |
| Dasher (segitiga) | Menandai arah, lalu menerjang |
| Target emas | Kabur dan menghilang; bernilai besar di Time Attack |

## Kemampuan
Pilih sampai 2 lewat menu **Kemampuan** (slot 1: Shift, slot 2: Q atau E). Beberapa mode membatasi atau menentukan kemampuan sendiri (mis. Shadow Run hanya Dash dan Shield; misi tertentu melarangnya).

## Tips per mode
- **Arena Classic / Build & Survive**: jangan terjebak di sudut. Di Build & Survive, pilih upgrade yang saling melengkapi; slot hanya 5.
- **Time Attack**: rantai kill tanpa jeda untuk combo. Kejar target emas saat aman.
- **Endless Survival**: ancaman naik tiap 30 detik, boss tiap 5 wave. Upgrade tidak dibatasi slot, jadi spesialisasikan build.
- **Crystal Hunt**: kristal yang dijaga musuh baru bergerak setelah kamu mendekat. Manfaatkan rintangan.
- **Zone Control**: berdiri di zona sampai penuh. Zona yang ditinggalkan terlalu lama kembali netral, jadi berputar antar zona. Musuh di dalam zona menghentikan proses.
- **Core Escort**: inti hanya bergerak saat kamu dekat. Bersihkan jalur di depannya.
- **Shadow Run**: kamu bergerak lebih pelan dan tidak bisa menembak. Bersembunyi di semak hijau, hindari kerucut pandang merah, jangan menyentuh penjaga.
- **Closing Ring**: garis putus-putus menunjukkan zona berikutnya. Pindah lebih awal.
- **Boss Rush**: serangan besar selalu diberi peringatan (garis putus-putus atau lingkaran merah). Baca polanya, lalu serang di sela-selanya.
- **Hazard Lab**: lantai oranye berkedip artinya akan aktif. Sakelar (lingkaran magenta) membuka pintu.
- **Tactical Trials**: aturan misi ditampilkan sebelum mulai. Baca baik-baik.

## Progres
- Rekor dan level tersimpan per mode di browser. Level berikutnya terbuka setelah level sebelumnya dimenangkan.
- 12 pencapaian dibuka dari kejadian saat bermain. Lihat di menu **Pencapaian** dan **Statistik**.
- Tombol **Lanjutkan** membuka mode atau level terakhir.
- **Pengaturan**: kurangi partikel dan efek layar, tampilkan FPS, ukuran dan posisi joystick, reset data.
