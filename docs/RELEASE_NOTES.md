## Mufa Arena v1.0.0 🎮

Game arena arcade-survival yang berjalan di browser. **HTML5 Canvas + JavaScript murni**, tanpa library, tanpa gambar atau audio. Semua visual digambar lewat kode.

**Main sekarang:** https://faris-it.github.io/arena-game/

### Isi rilis
- **12 mode** + tutorial interaktif: Arena Classic, Time Attack, Endless Survival, Crystal Hunt, Zone Control, Core Escort, Shadow Run, Closing Ring, Boss Rush, Build & Survive, Hazard Lab, Tactical Trials
- **8 boss** dengan pola serangan berbeda dan peringatan sebelum serangan besar
- **6 kemampuan**: Dash, Shield, Pulse, Mine, Slow Field, Heal
- **40+ level** di mode berlevel (level terbuka bertahap)
- **12 achievement**, statistik, rekor lokal, tombol Lanjutkan
- Desktop (WASD + mouse) dan HP (joystick, ukuran dan posisi bisa diatur)
- Progres tersimpan di browser (localStorage), tanpa akun

### Cara menjalankan
Unduh `arena-game-v1.0.0.zip`, ekstrak, lalu buka `index.html`. Atau main langsung lewat tautan di atas.

### Pengujian
`npm test` menjalankan bot yang memainkan semua mode dan level (55 pemeriksaan). Pengujian sentuhan di perangkat nyata masih dilakukan manual.
