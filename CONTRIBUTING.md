# Berkontribusi

Terima kasih sudah tertarik! Proyek ini sengaja dibuat **tanpa library dan tanpa aset**: semua visual digambar lewat Canvas 2D/CSS.

1. Fork lalu buat branch: `git checkout -b fitur/nama-fitur`
2. Jalankan game: buka `index.html`, atau `npm start` lalu buka `http://localhost:8080`
3. Jalankan tes sebelum commit: `npm test` (bot memainkan semua mode dan level, butuh Node 18+)
4. Gunakan pesan commit singkat, mis. `feat: tambah boss baru`, `fix: tembakan ganda meleset`
5. Buka Pull Request

Ide yang disambut: boss baru (lihat `data/bosses.js`), level baru untuk mode berlevel, kemampuan baru (`data/abilities.js`), terjemahan, dan perbaikan keseimbangan.
